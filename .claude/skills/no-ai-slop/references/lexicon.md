# Lexicon

Word and phrase lists. Load this when SKILL.md's tiers are not enough: a thorough review, a contested edit, or when the writer wants the reasoning behind a flag.

Nothing here is banned in a quotation, a title, a proper name, or an example that discusses the phrase rather than uses it.

## Tier 1: always cut

These almost never survive in unedited human prose.

| Word or phrase | Usually means | Plainer choice |
|---|---|---|
| delve (into) | look at, examine | look at, dig into |
| tapestry / realm / landscape (abstract) | (filler noun) | cut, or name the actual thing |
| underscore / highlight (verb) | show, stress | show |
| leverage (verb) | use | use |
| utilize | use | use |
| facilitate | help | help |
| harness (metaphor) | use | use |
| foster / cultivate | build, grow | build |
| empower / elevate / unlock | improve, enable | improve, let |
| streamline | simplify | simplify |
| testament to | shows | shows |
| multifaceted / intricate / interplay | complex | complex, or name the parts |
| meticulous | careful | careful |
| paramount | most important | most important |
| transformative / paradigm shift / game changer | (overclaim) | say the concrete change |
| cutting-edge / groundbreaking (figurative) | new | new, or the version number |
| embark / supercharge | start / speed up | start, speed up |
| ever-evolving | changing | changing |
| beacon | (filler noun) | cut |
| myriad / plethora | many | many, or a number |
| it's worth noting / it's important to note / it bears mentioning | (padding) | cut |
| in today's (fast-paced) world / in today's ... landscape | (throat-clearing) | cut |

| a double-edged sword | (cliché) | name the specific tradeoff |
| nestled / in the heart of | (travel-brochure) | just say where it is |

## Tier 2: cut on density

One is fine. Two or more in a paragraph is a tell.

crucial, pivotal, vital, vibrant, robust, seamless, frictionless, enhance, showcase, garner, bolster, spearhead, poised, notably, moreover, furthermore, additionally, nuanced, holistic, elucidate, encompass, align with, actionable, impactful, learnings, cornerstone, catalyst, synergy, ecosystem (figurative), framework (figurative), deep dive, state-of-the-art, world-class, renowned, breathtaking, must-visit, stunning, profound, rich (figurative), boasts.

## Tier 3: context only

key, important, significant, various, effective, valuable, powerful, essential.

Ordinary words. Flag only when they cluster with Tier 1 or Tier 2 hits, or when they stand in for a specific fact ("a significant improvement" where a number belongs).

## Adverbs

Cut when they add nothing. Keep when they carry emphasis, uncertainty, contrast, or the writer's spoken rhythm. An adverb propping up a weak verb means the verb is wrong: "runs quickly" becomes "is fast" or the number; "significantly improves" becomes the measured delta.

Frequent offenders: really, just, literally, genuinely, honestly, simply, actually, deeply, truly, fundamentally, inherently, inevitably, incredibly, interestingly, importantly, crucially, remarkably, arguably, quietly.

"Quietly" deserves its own line. Models reach for it to make a mundane fact feel significant: "quietly orchestrating workflows," "the one that quietly suffocates everything else."

## Throat-clearing openers

Cut and state the content.

Here's the thing / Here's what X / Here's why X / Here's the kicker / Here's where it gets interesting / Here's what most people miss / Here's the deal / The uncomfortable truth is / It turns out / The real X is / Let me be clear / The truth is / I'll be honest / I'm going to be honest / Can we talk about / The catch? / The brutal truth? / Sound familiar? / As [role], I...

Also the hedged-enumeration opener, which announces a vague list instead of committing: "There are several ways to...", "There are a few things to consider", "Generally speaking,". Give the specific answer first.

## Emphasis crutches

Delete. They add no meaning.

Full stop. / Period. / Let that sink in. / This matters because / Here's why that matters / Make no mistake / This is genuinely hard / actually matters / This is what X actually looks like.

## Pedagogical hand-holding

Cut unless the audience genuinely needs a teacher.

Let's break this down / Let's unpack this / Let's explore / Let's dive in / Let's delve into / Think of it as... / Think of it like... / Imagine a world where... / here's what you need to know / without further ado.

"Think of it as" analogies are often less clear than the concept they explain.

## Meta-commentary

The text should move, not announce its own structure.

Hint: / Plot twist: / Spoiler: / You already know this, but / But that's another post / X is a feature, not a bug / The rest of this essay explains... / Let me walk you through... / In this section, we'll... / As we'll see... / In conclusion / To sum up / In summary / Overall, / As we've seen in this section... / And so we return to where we began. / Whether you're a X or a Y...

## Abstract metaphor nouns

These read as technical but usually have a plainer, concrete word. Common in engineering writing.

substrate (base), wedge (add), vector (way, method), locus, vantage, nexus, primitive (as noun), surface (as in "API surface"), bedrock, scaffolding (metaphor), modality, gold-plating (more than the job needs), ratchet (name the mechanism, or "a limit that only tightens"), evacuate (move out), endgame (the last phase), north star, flywheel.

## Copula dodges

Models avoid plain *is* and *has* because repetition penalties push them toward fancier verbs.

| Avoid | Use |
|---|---|
| serves as | is |
| stands as | is |
| marks (meaning "is") | is |
| represents (meaning "is") | is |
| boasts | has |
| features | has |
| offers (meaning "has") | has |

## Vague declaratives

Announcing importance without naming the thing. Replace with the specific implication, or cut.

The reasons are structural / The implications are significant / This is the deepest problem / The stakes are high / The consequences are real.

Before: "The implications for the team are significant."
After: "Two engineers now own a service that used to have six."

## Vague attributions

If you cannot name the source, you do not have one. Never invent one.

Experts argue / Experts believe / Industry reports suggest / Observers have cited / Several publications have noted / Some critics argue / studies show / research shows / widely regarded as.

Models also inflate quantity: "several publications" for two, one person's view presented as consensus.

## Grandiose stakes inflation

Scale the claim to the actual stakes. A post about API pricing is not a meditation on civilization.

This will fundamentally reshape how we think about everything / will define the next era of computing / will define the next decade / something entirely new / changes everything / the future of X.

## Aphorism formulas

Ordinary claims dressed as reusable pull-quotes. State the concrete claim instead.

X is the Y of Z / X is the new Y / X becomes a trap / X is not a tool but a mirror / the language of / the currency of / the architecture of / X is where Y meets Z.

Before: "Symmetry is the language of trust."
After: "Symmetric layouts often feel more predictable to users."

## Persuasive authority tropes

Pretending to cut through noise, then restating an ordinary point with ceremony.

The real question is / at its core / in reality / what really matters / fundamentally / the deeper issue / the heart of the matter / the reality is simpler / History is unambiguous on this point / but none of them is the real story. The real story is...

## Fake-candid openers

A staged pause before a routine point.

Honestly? / Look, / Here's the thing / The thing is / Let's be honest / Real talk / And yes, since we're being honest / This is not a rant; it's a diagnosis.

Mid-sentence "honestly" and "look" are ordinary in casual writing. The tell is the standalone theatrical opener.

## Chatbot artifacts

I hope this helps / Of course! / Certainly! / You're absolutely right! / Great question! / Would you like... / Want me to...? / Should I continue? / let me know / here is a...

Reasoning-chain leftovers: Let me think... / Step 1: / Breaking this down... / First, let's consider...

Acknowledgment loops: "You're asking about X..." Just answer.

## Cutoff disclaimers and speculative gap-fill

as of my last training update / Up to my last knowledge update / While specific details are limited / based on available information / not publicly available / maintains a low profile / keeps personal details private / prefers to stay out of the spotlight / likely [grew up / studied / began] / it is believed that.

Two tells in one: the model says it could not find a source, then fills the gap with a plausible guess. Say what the source does not show, or cut the sentence.

## Hedge stacks

to be fair / it's also possible / could potentially / might arguably / in some cases it may / this is an inference.

One qualifier per claim, and only when the source supports it.

Before: "It could potentially possibly be argued that the policy might have some effect on outcomes."
After: "The policy may affect outcomes."

## Generic positive endings

The future looks bright / Exciting times lie ahead / journey toward excellence / a step in the right direction / only time will tell / the possibilities are endless.

Cut the paragraph. End on the last concrete fact.

## Hyphenated pair overuse

third-party, cross-functional, client-facing, data-driven, decision-making, well-known, high-quality, real-time, long-term, end-to-end.

Keep the hyphen before a noun ("a high-quality report"). Drop it after the verb ("the report is high quality").

## Forensic artifacts

Leftovers from the generation pipeline. Strip them.

- Citation markup: `citeturn0search0`, `contentReference[oaicite:0]{index=0}`, `oai_citation`, orphan footnote characters.
- UTM parameters: `utm_source=chatgpt.com`, `utm_source=openai`, `utm_source=copilot.com`, `referrer=grok.com`.
- Placeholder text: `[Your Name]`, `[INSERT SOURCE URL]`, `2026-XX-XX`, square-bracketed instructions.
- Unicode obfuscation: zero-width space (U+200B), zero-width joiner (U+200D), soft hyphen (U+00AD), dense non-breaking spaces, Cyrillic or Greek homoglyphs for Latin letters. Normalize to plain NFC.
- Markdown bleeding: `**bold**` left in an email, a DM, or a Word doc.
